About Smart HRMS

Automated Human Resource Management Platform

Smart HR Management System is an enterprise-grade Django web application engineered to solve end-to-end human resource operations. It features strict role-based access control (RBAC), automated recruitment pipelines, workforce oversight, performance tracking, HR advisory workflows, and executive analytics.

System Roles & RBAC
  • Administrator: Global authority across all workforce data, recruitment approvals, disciplinary rulings, and department structures.
  • HR Manager: Manages recruitment postings, candidate interviews, employee onboarding, performance evaluations, and advisory recommendations.
  • Employee: Submits weekly work reports, reviews performance feedback, and tracks company notifications.
  • Candidate: Explores vacancies, submits applications, and tracks hiring status.
Core Modules
1. Recruitment Lifecycle From job vacancy creation, applicant pipeline, to administrative hiring approvals and offer dispatches.
2. Workforce Directory Department-based hierarchy, employee codes, designations, joining dates, and employment status management.
3. Governance & Adjudication HR recommendation reviews, performance warnings, PIP escalation, and termination workflows with full confirmation safeguards.
Technology Architecture
Django 4.2+ Backend Engine
PostgreSQL / SQLite Relational Database
Bootstrap 5 + Custom CSS Responsive Interface
Allauth & RBAC Security & Auth
